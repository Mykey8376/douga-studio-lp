# 動画編集スタジオ LP

8枚のLP画像と2箇所の公式LINE CTAを配置した静的サイトです。

- 配信ファイル: `dist/`
- CTAリンク: https://lin.ee/nAMWXRZ
- 画像: WebP、縦横比を保持して表示

## Vercel

このリポジトリをImportし、Framework PresetをOther、Output Directoryをdistに設定します。ビルドコマンドと環境変数は不要です。設定はvercel.jsonにも記載しています。

## ローカル確認

`python -m http.server 8000 --directory dist`
